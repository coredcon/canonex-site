---
title: Keyboard shortcuts
description: The keys that keep your hands on the keyboard and your eyes on the table.
section: Reference
order: 1
---

| Shortcut | Where | What it does |
|---|---|---|
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | Anywhere | Summon a record |
| <kbd>Ctrl</kbd> + <kbd>J</kbd> | Anywhere in a campaign | Jot a note, and tag records with `@name` |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> | Codex | Search records |
| <kbd>Ctrl</kbd> + <kbd>V</kbd> | Desk | Paste a web address as a reference card |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> | Desk | Undo |
| <kbd>Ctrl</kbd> + <kbd>Y</kbd> or <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> | Desk | Redo |
| <kbd>Esc</kbd> | Anywhere | Close the current palette or dialog |
